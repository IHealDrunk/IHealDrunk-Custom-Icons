# Eclipse Icons

A custom World of Warcraft icon pack created by IHealDrunk.

## Style

Eclipse features:

- Custom shadow treatment
- Glow effects
- Gloss highlights
- Dark fantasy inspired border design

## Installation

1. Download the Eclipse Icons pack.
2. Extract the ICON folder and place inside your World of Warcraft/_retail_/Interface
3. Reload World of Warcraft.
